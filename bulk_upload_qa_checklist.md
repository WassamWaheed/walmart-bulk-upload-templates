# Walmart Bulk Upload QA Checklist

## Before Upload
- [ ] Correct category/product type selected
- [ ] SKU values are unique
- [ ] Product identifiers are verified
- [ ] Required attributes are complete
- [ ] Variant values are consistent
- [ ] Images and URLs are valid
- [ ] Pricing and fulfillment fields are reviewed

## After Upload
- [ ] Processing report reviewed
- [ ] Failed SKUs isolated
- [ ] Root causes logged
- [ ] Source file corrected
- [ ] Live content verified
- [ ] Variants render correctly
